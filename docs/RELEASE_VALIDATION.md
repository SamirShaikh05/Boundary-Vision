# Release validation plan

This is a focused validation checklist. A completed build or a worker capability response is not evidence that model inference or all media workflows pass.

## Per-release checks

1. **Image inference:** On a clean Windows account, install one model, process real JPEG and PNG cricket images with both YOLO26n and YOLO26l, inspect the preview and output files, and compare class IDs/names and confidence values with the source model output. Repeat one image with no detections. Check the selected confidence threshold and output name collision handling.
2. **Video cadence:** Use a known-duration video with visible timing markers. Run at inference FPS below, equal to, and above output FPS. Verify the selected model and threshold, progress, output duration, output frame rate, latest-frame policy between inferences, and playback/save behavior. Check source audio offset on an audio-bearing clip.
3. **Variable frame rate:** Use an actual VFR fixture with independently known presentation timestamps. Compare input `ffprobe` packet/frame timestamps and output frame PTS/duration; inspect the inference sample-to-source-frame mapping across irregular intervals and timestamp discontinuities. Include a timestamp gap and a non-zero stream start time. A synthetic pipeline smoke check is not a substitute for real VFR media.
4. **Annotation formats:** Enable YOLO TXT, Pascal VOC XML, and CreateML JSON separately and together. Check normalized versus pixel coordinates, class mapping, image dimensions, empty detections, per-frame filenames, and that exports correspond to inference sample frames.
5. **Cancellation and cleanup:** Cancel image batches and videos during probing, decoding, inference, and encoding. Confirm the UI returns to an idle state, no partial final output is presented as complete, and the job's temporary staging folder and child processes are gone. Also test disk-full and unwritable output paths.
6. **LabelImg integration:** Select a directory containing `labelImg.py`, restart Boundary Vision and confirm it is remembered, reject a folder without the script, and test successful launch with `py labelImg.py`. Test missing `py`/Python and a script that fails during startup; confirm useful errors are shown. Complete image inference, export YOLO and Pascal VOC datasets, check filenames/class list/coordinates and paths containing spaces, then inspect and save in LabelImg. Confirm CreateML-only runs can export either compatible format, existing files are preserved, and video frames are not opened as an image dataset.
7. **Model Manager:** Test development-copy installation and hosted installation from the currently published `models-v1` GitHub Release, plus size mismatch, SHA mismatch, class incompatibility, missing/incompatible dependencies, checkpoint load/inference errors, offline/HTTP failure, cancellation, select/restart persistence, removal of managed copies, and protection of originals and an in-use model. Python version metadata is not used as a compatibility gate. The release asset sizes and SHA-256 metadata match the registry, but an in-app hosted download and inference remain unverified. For hosted delivery, compare each downloaded object with independently fetched origin bytes.
8. **Packaged clean Windows:** Use a clean Windows 10/11 x64 VM without Python, Node, FFmpeg, a developer checkout, or manually adjusted PATH. Install and launch, inspect signature/warning behavior, run capability detection, complete image inference with each model, exercise optional managed model install/remove, test spaces and non-ASCII paths, restart, upgrade over an existing install, uninstall, and verify user data/model retention policy. Confirm video processing reports a clear FFmpeg/FFprobe requirement when absent, then install a compatible pair on `PATH` and exercise video inference. Repeat on a second Windows account if user-data isolation matters.
9. **Application updates:** On a signed test build configured with the actual public GitHub owner/repository, test startup and manual checks for current, newer, unavailable, and offline cases. Confirm no automatic download, inspect progress and retry after an interrupted download, then verify a downloaded update cannot restart during image/video inference or model installation/validation. Install only after an explicit restart action; confirm settings, installed model versions, and selected model version remain unchanged.
10. **Optional video tools:** Confirm the installer contains neither `ffmpeg` nor `ffprobe`, and that image inference works without either tool. With both tools absent from `PATH`, verify video processing fails with a concise setup message; with a compatible pair present, confirm the video worker receives their resolved paths and processes the fixture.

## Previously recorded checks

The following results are carried forward from earlier validation records; they were not rerun during this documentation reconciliation. Checkpoint size and hash results below were rechecked during this pass.

- Earlier records say `npm run build` completed successfully, including TypeScript checks and Vite output.
- Earlier records say `npm run build`, the PowerShell package-script parser, and `npm audit --omit=dev` completed successfully; the production npm dependency graph reported zero advisories.
- Earlier packaging records say `npm run package:win` produced an unsigned `0.1.0` NSIS installer. Its bundled worker returned a CPU capability record using Python 3.15.2. This verifies the frozen worker starts and reports capabilities, not that either checkpoint can infer.
- An earlier record says the standalone PyInstaller worker started and returned a CPU capability record using its bundled Python, without an activated virtual environment.
- An earlier synthetic VFR smoke fixture compared FFprobe timestamps with decoded frame count and exercised timestamp-gap handling; that does not establish correctness on camera/editor-generated VFR content.
- In this documentation pass, both source checkpoint sizes and SHA-256 values were checked against the registry. The packaging script also checks sizes/hashes when packaging development sources.
- Earlier records apply to a previous installer build that included FFmpeg and FFprobe. Current packaging no longer includes either executable; this change has not yet been verified by producing and inspecting a new installer.

No image inference with either checkpoint, complete user video export, VFR conformance pass, annotation-output review, or clean-machine installed inference result is established by the recorded evidence. These checks require representative media and a clean Windows environment. They were not run during this documentation reconciliation.

The LabelImg UI and IPC have been build-checked, but no real LabelImg process launch or exported-dataset round trip is established by the recorded evidence.
